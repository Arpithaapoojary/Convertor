# DocSuite

DocSuite is a professional, client-side toolkit for document and image conversions. It runs entirely in the browser and performs PDF, image, text, and data transformations without any server uploads.

## Key features
- Merge, split, rotate, and inspect PDFs
- Convert images to/from PDF and common raster formats (JPEG, PNG, WebP)
- Compress and optimize images client-side
- Generate and scan QR codes and barcodes
- Text utilities: transform, diff, and export to PDF
- CSV/JSON conversion, JSON formatting and validation

## Quick start
1. Clone the repository:

```bash
git clone https://github.com/Arpithaapoojary/DocSuite.git
cd DocSuite
```

2. Serve locally (Python):

```bash
python -m http.server 8000
```

Then open http://localhost:8000 in your browser.
