# Convertor

A versatile, modern web-based conversion and utility toolkit featuring PDF tools, image converters, QR code generator/scanner, text transformation, and data format tools.

## 🚀 Features

- **PDF Utilities**: Merge, split, compress, and convert PDF documents.
- **Image Conversion & Processing**: Convert between PNG, JPEG, WEBP, SVG, resize, and compress.
- **QR Code Tools**: Generate custom QR codes and scan from images or camera.
- **Data & Text Tools**: JSON/CSV/XML conversion, Base64 encoder/decoder, text case transformations, hash generation, and formatting.
- **Client-side & Secure**: Fast and private processing directly in the browser.

## 🛠️ Tech Stack

- **HTML5 & CSS3** (Responsive design, dark/light theme)
- **Vanilla JavaScript**
- **Client-Side Libraries**: PDF-lib, JSZip, QRCode.js, etc.

## 📦 Getting Started

Simply open `index.html` in your web browser or serve using any static file server:

```bash
# Using VS Code Live Server or Python
python -m http.server 8000
```
